kan-do is a kanban board in your browser and an MCP server in one small Go program, so you and your coding agents work on the same tasks. The whole board is one folder, and a private git repo keeps it in step on every machine you use. No account, no server.

Work in progress. See [docs/SPEC.md](docs/SPEC.md) for what it does and how it's built.
